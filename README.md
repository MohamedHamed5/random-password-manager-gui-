# random-password-manager-gui-
a short idea:

Random Password Manager with GUI
A simple and secure desktop application built with Python and Tkinter that allows users to generate strong random passwords and save them along with website and username information. The app features a clean graphical interface, automatic file storage, masked password display, search functionality, and the ability to open the saved password file directly.
from the features:
Random Password Generator with: customizable length (10–17 characters)
Search Functionality: Quickly find saved entries using a search box
